# Contributing

Small, focused fixes and improvements are welcome.

1. Fork the repository and create a branch.
2. Run `npm install`.
3. Make the change and add or update tests where behaviour changes.
4. Run `npm test` and `npm run build`.
5. Open a pull request explaining the problem and the chosen approach.

Changes to argumentation semantics should include a minimal framework demonstrating the expected extensions and cite the relevant formal definition.
