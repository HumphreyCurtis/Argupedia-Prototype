    What is an argumentation scheme?

    An argumentation scheme is a recurring pattern of reasoning: a set of premises supports a conclusion, while critical questions expose assumptions that may weaken it. Argupedia uses the selected scheme to structure each contribution and the questions available to challenge it. Argumentation Schemes (Part 1), John Danaher.

    What is a Dung-style argumentation graph?

    A Dung-style framework represents arguments as nodes and attacks between them as directed arrows. Formal semantics can then identify which arguments are accepted, rejected or undecided from the pattern of attacks—not simply declare which speaker “won”. Introduction to argumentation frameworks.
